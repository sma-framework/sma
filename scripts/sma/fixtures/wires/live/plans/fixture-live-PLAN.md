# фикстура описи — ЖИВАЯ СВЯЗЬ

У плана ЕСТЬ парная сводка, поэтому он закрыт и судим.

Три формы объявлены нарочно вместе: структурная связь, две записи artifacts и две строки
прозой. Форма `path + contains` сильнее свободного следа — она называет файл.

Этот случай — ЖИВОЙ целиком: каждая проверяемая запись обязана стать зелёной, иначе прибор
умеет только краснеть, а такой прибор бесполезен ровно так же, как мягкий.

Маркер `WIRE_MARKER_DECLARED_ONLY` стоит в этом тексте нарочно и не объявлен ни одной
записью: он сторожит зону поиска. Ни один файл дерева его не несёт, поэтому найтись он может
только в одном случае — если сборщик начнёт сканировать каталог планов и поздравит сам себя
собственным объявлением. Тот же замок на стороне вердикта живёт отдельным случаем
`self-declared/`, где такой след объявлен и обязан краснеть.

Второй путь artifacts написан с чужим префиксом `../synthetic-elsewhere/`: без правила
переписывания корня он не резолвится нигде, с правилом — находит тот же файл.
